# Ki Sci Iki — 都市と科学がであう場所

研究を都市空間に実装する共創プロジェクト「Ki Sci Iki」（Academimic × 日建設計総合研究所）の事業共創サイト。

公開URL：https://ki-sci-iki.vercel.app/

| ファイル | 内容 |
|---|---|
| `index.html` | メイン。プレゼン兼LP。1画面ずつ ↓ で進む映像的な構成：街の空き地を素通りする人 → 大学のガラスドームに閉じ込められた研究の光 → 光が空き地に流れ込み光の木（研究＋アート）が育ち、人が立ち止まる → 上空から見た街で、すき間が灯り「知の交差点」がつながる → 5つのピース → チーム → 仙台駅の実例 → 一言が葉になる → 体験デモ → 出すもの／得られるもの → 進め方 → 相談 |
| `cinematic.html` | シネマ版（スライド型・夜→夜明けの演出）。登壇用 |
| `vercel.json` | `/cinematic` でシネマ版を開けるようにする設定 |

## 操作
- 次へ：↓ → Enter スペース ／ 前へ：↑ ←
- Home / End：最初・最後 ／ F：全画面
